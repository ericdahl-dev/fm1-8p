# The page's fonts

Self-hosted, so the page loads no font from another site. Each folder holds the latin subset of one family as
woff2, unmodified, and the family's license as `OFL.txt`. All three are under the SIL Open Font License,
Version 1.1. The files come from the Fontsource npm packages, version 5.3.0.

| Folder | Family | Weights | Copyright | Fontsource package |
|---|---|---|---|---|
| `doto/` | Doto | 800, 900 | The Doto Project Authors (https://github.com/oliverlalan/Doto) | `@fontsource/doto` |
| `atkinson-hyperlegible/` | Atkinson Hyperlegible | 400, 700 | Braille Institute of America, Inc. | `@fontsource/atkinson-hyperlegible` |
| `atkinson-hyperlegible-mono/` | Atkinson Hyperlegible Mono | 400, 600 | The Atkinson Hyperlegible Mono Project Authors (https://github.com/googlefonts/atkinson-hyperlegible-next-mono) | `@fontsource/atkinson-hyperlegible-mono` |

Doto, a dot-matrix face, is used only for the display windows: the heading FM1-8P, the boot readout and the
tone names. Atkinson Hyperlegible sets the text, Atkinson Hyperlegible Mono the code and the installer's status.
