# UI mockups

The PNGs here (`membrane/`, `night-panel/`, `boot/`, `compare.png` and the font specimens) are drawn by
`render.py`. Their text in the host's font is Terminus 8x16 (SIL OFL 1.1): `render.py` reads it at run time
from fm1-dock's `firmware/gen/felucca_font.h`; no font file or glyph tables are in this repository (only
the glyphs as drawn in the PNGs). fm1-8p's own
display font, `display_font.h`, is an original face generated by `render.py` (GPL-3.0-or-later).
